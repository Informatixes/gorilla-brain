# Captura de conocimiento

1. Identificar la fuente.
2. Separar hechos, decisiones, propuestas e hipótesis.
3. Enlazar el contexto relevante.
4. Registrar contradicciones sin sobrescribirlas.

El [[agents/Analista|Analista]] prepara la incorporación y el [[agents/Coordinador|Coordinador]] decide qué especialista debe intervenir.
